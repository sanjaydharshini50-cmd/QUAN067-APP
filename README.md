This repository features the "Quantitative Multi-Asset Financial Intelligence & Backtesting Platform". It is designed to automatically collect, process, and analyze historical market data across different asset classes, such as Gold, Bitcoin, and NVIDIA. The platform applies quantitative techniques to calculate indicators including SMA, EMA, volatility, Sharpe ratio, and maximum drawdown. Additionally, it includes a robust strategy backtesting engine that simulates predefined quantitative strategies while factoring in initial capital, transaction costs, and entry/exit signals. The ultimate goal is to transform raw market data into actionable financial insights through interactive visualizations and cross-asset correlation analysis
